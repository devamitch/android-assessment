# Wallet Watchlist

Take-home for an Android developer.

## Start here

You are on **`main`**.

**Check out `assessment` to get the assignment:**

```bash
git checkout assessment
```

Then open **`assessment.md`** and follow it.

## What is in the codebase

- `app/src/main/java/com/watchlist/WatchlistStore.kt` - watchlist and treasury balance
- `app/src/main/java/com/watchlist/WatchlistActivity.kt` - screen behavior
- `app/src/main/res/layout/activity_watchlist.xml` - layout
- `app/src/main/AndroidManifest.xml` - app entry
